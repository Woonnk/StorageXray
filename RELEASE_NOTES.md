# StorageXray 0.2.1

Portable Windows x64 storage explorer with a clickable map, largest-file search, exact duplicate matching, cleanup review, and local scan history.

- Readable dark drive, category, and sort dropdowns.
- Disk-backed scan inventories, bounded parallel traversal, and paged results.
- Cloud/link exclusions and review before recycling files.

The app and XAML compile. The unchanged 0.2 core passed 25 functional checks and a one-million-record metadata stress test. Native Windows scanning, SQLite loading, and recycling still need verification. The screenshots confirmed that the 0.2 Windows interface launched; visual confirmation of the 0.2.1 dropdown patch is pending.

The Windows ZIP should be attached as a release download. Extract it and open StorageXray.exe. See README.md for details and limitations.
